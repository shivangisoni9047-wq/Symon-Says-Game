# Simon Says Game

A simple and interactive memory game developed using HTML, CSS, and JavaScript.

## About the Project

Simon Says is a memory-based game where the player has to remember and repeat the sequence of buttons shown by the game. The sequence becomes longer as the player progresses through different levels.

## Features

- Interactive gameplay
- Increasing difficulty with each level
- Score and level tracking
- Responsive design
- Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Play

1. Open the game.
2. Press any key to start.
3. Watch the sequence shown by the game.
4. Repeat the same sequence by clicking the buttons.
5. The sequence gets longer as you complete each level.
6. Try to achieve the highest score possible.

## Project Structure

- `Index.html` - Structure of the game
- `style.css` - Styling and design
- `app.js` - Game logic and functionality
